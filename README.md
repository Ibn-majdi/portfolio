# Ibn Majdi — Portfolio

Personal portfolio website of **Ibn Majdi**, AI content creator and visual
researcher based in Alexandria, Egypt.

A single-page static site: no build step, no dependencies. Open `index.html`
or serve the folder with any static server.

## Structure

- `index.html` — the whole page (sections: identity, career timeline, AI work, experience, contact)
- `styles.css` — all styles, responsive down to mobile
- `script.js` — scroll-reveal animations, mobile menu, footer year
- `assets/` — portraits, AI experiment images, film visual development, AI videos

Hosted with GitHub Pages.
